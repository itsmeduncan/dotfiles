# TypeScript / Node.js

- Package manager: pnpm (`pnpm add`, `pnpm install`, `pnpm run`)
- Framework: Next.js with App Router, React
- Linting: ESLint
- Formatting: Prettier
- Style: 2-space indent, single quotes, strict mode, `satisfies` over `as`
- Prefer optional chaining, nullish coalescing, `const` by default
- Use `interface` for object shapes, `type` for unions/intersections
